# Content Schema

All published content should contain the following frontmatter.

```yaml
title:
description:
pubDate:
updatedDate:
draft:

documentType:
theme:
status:

sourceNote:
domainPath:

canonical:
```

## documentType

Allowed values:

* article
* field-note
* checkpoint
* research-note
* experiment
* project-journal

## theme

Human-readable topic area.

Current values are provisional and may evolve over time.

Do not treat themes as permanent taxonomy.

## status

Allowed values:

* observation
* working-theory
* checkpoint
* archived

## sourceNote

Optional note describing where the material originated.

Examples:

* Deep Field Works launch notes
* AI Adoption project
* Personal observation
* Prototype review

## domainPath

Curated reading pathway.

Domains are manually managed and may evolve.

Do not treat domains as tags.

## canonical

Indicates whether this is the preferred published version of the idea.
