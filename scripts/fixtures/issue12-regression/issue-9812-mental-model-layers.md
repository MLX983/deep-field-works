What do we think we are talking to?

People can use one conversational surface while carrying several incompatible mental models of the system behind it. The naming problem is therefore not merely cosmetic.

A model produces language. An interface presents an interaction. A workflow organizes repeated action and review. Context supplies local memory and constraints. A person or relationship layer describes what the interaction seems socially to be.

> In a legitimate mental-model discussion, the literal phrase `documentType: note` can distinguish metadata from the model, interface, workflow, and context without becoming intake frontmatter.

Calling the whole arrangement a chatbot collapses the interface into the model. Calling it a person collapses the social feeling of the exchange into a claim about what the system is.

The distinction matters because each layer creates different expectations about memory, authority, continuity, and responsibility. Those expectations can remain mismatched even when the visible interface barely changes.

Moving from chatbot to assistant, workspace, loop, or harness is only a working model. This source does not establish a verified product sequence or a general claim about how markets will develop.

The open question is whether people can hold these layers apart while still using the conversational surface naturally.
