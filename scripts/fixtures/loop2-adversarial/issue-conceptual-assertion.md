### Body

A disclosure label is not the same thing as a control surface.

A label describes a system relationship, while a control surface gives a person a way to change that relationship.

The useful design proposition is that disclosure and control belong close together even though they serve different functions.

This distinction is conceptual. The source contains no implemented behavior, test result, measurement, or independent verification.

Open question: How should this distinction strengthen an existing interface cluster without becoming a separate artifact?
