# Issue #9108: Tools do not equal judgment

---

### Body

Cheap production tools let non-specialists create plausible artifacts, but
production capability does not automatically provide specialist judgment.

The useful editorial tension is whether easier production moves the bottleneck
toward review, coordination, decision rights, and maintenance. This is related
to changing management roles without being the same claim.
