### Body

Observation: The evaluation burden may become the limiting factor as organizations add more agents.

Working model: More agents create more outputs, edge cases, tool calls, handoffs, and policy boundaries, which makes evaluation combinatorial rather than linear.

Open question: What shared operating material is required before an agent layer becomes trustworthy?

The useful warning is that building the loop matters more than building the agent when judgment work scales faster than execution.
